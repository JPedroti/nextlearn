# Aula de exemplo para a demonstração

Aula escrita pelo Cauã para a demo. Na gravação, o professor **cola este texto no app** em "Nova aula": assim o
vídeo mostra o fluxo de verdade (o professor escreve a aula uma vez e o app gera as versões). O repositório não tem
nenhum comando que crie professores, alunos ou respostas prontas.

- **Título:** Equações do 2º grau: fórmula de Bhaskara
- **Série sugerida:** 9º ano do ensino fundamental (ou 1º ano do ensino médio)

## Texto da aula (copiar tudo para o campo "Conteúdo")

```
Uma equação do 2º grau é toda equação que pode ser escrita na forma:

ax² + bx + c = 0

Onde a, b e c são números reais e a ≠ 0. O "a" é o coeficiente do x², o "b" é o coeficiente do x, e o "c" é o termo independente (o número sozinho, sem x).

Para resolver uma equação do 2º grau, usamos a fórmula de Bhaskara:

x = (-b ± √Δ) / (2a)

Onde Δ (delta) é o discriminante:

Δ = b² - 4ac

O valor de delta nos diz quantas soluções a equação tem:
- Se Δ > 0: duas soluções reais diferentes
- Se Δ = 0: uma solução real (as duas raízes são iguais)
- Se Δ < 0: nenhuma solução real

Exemplo: resolver x² - 5x + 6 = 0
a = 1, b = -5, c = 6
Δ = (-5)² - 4·1·6 = 25 - 24 = 1
x = (5 ± √1) / 2
x = (5 ± 1) / 2
x₁ = 3, x₂ = 2
```

## Questões (com o gabarito)

**1.** Qual é a fórmula de Bhaskara para resolver ax² + bx + c = 0?
- A) x = (-b ± √(b² - 4ac)) / 2a ✅
- B) x = (b ± √(b² + 4ac)) / a
- C) x = (-b ± √(b² + 4ac)) / 2a
- D) x = (b ± √(b² - 4ac)) / a

**2.** Na equação 2x² + 3x - 5 = 0, qual é o valor do coeficiente b?
- A) 2
- B) 3 ✅
- C) -5
- D) 0

**3.** Calcule o delta (Δ) da equação x² - 6x + 8 = 0.
- A) Δ = -4
- B) Δ = 4 ✅ (36 - 32 = 4)
- C) Δ = 36
- D) Δ = 2

**4.** Se o delta de uma equação do 2º grau é negativo, o que isso significa?
- A) A equação tem duas soluções reais
- B) A equação tem uma solução real
- C) A equação não tem solução real ✅
- D) A equação tem infinitas soluções

**5.** Resolva a equação x² - 4x + 4 = 0. Qual é a solução?
- A) x = 0
- B) x = 2 ✅ (Δ = 0, raiz única)
- C) x = 4 e x = 0
- D) x = 2 e x = -2

## Como usar na demo

1. Entre como professor, abra a turma e clique em **Nova aula**.
2. Cole o título e o texto, preencha as 5 questões com as alternativas e marque a correta de cada uma.
3. Salve, ajuste os apoios dos alunos (cadastrados na hora pela equipe) e gere as versões adaptadas.
4. Revise e aprove as versões; publique a aula. Os alunos (integrantes da equipe, logados em outro navegador)
   respondem de verdade, e o painel mostra esses números.

As fórmulas das alternativas da questão 1 ganharam parênteses em relação à primeira versão, para a divisão por 2a
valer para o numerador inteiro, como na fórmula do texto.
