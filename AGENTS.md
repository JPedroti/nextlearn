# Instruções para assistentes de programação

Este repositório usa o [CLAUDE.md](CLAUDE.md) como guia único para qualquer assistente de IA que a equipe usar
(Claude Code, Qwen, ChatGPT, Cursor e outros). Leia esse arquivo inteiro e siga-o, começando pela seção 0
(identificar quem da equipe está falando, registrar o prompt e resumir o status a partir de `docs/cronograma.md`).
